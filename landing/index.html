Features

A little help with the everyday.

Designed to work well on everyday, low-cost Android phones.

Smart task scheduling

Pick from a shared task library or add your own. Recurring tasks fill each day's list automatically.

Auto-translated audio tasks

Write a task once, in any language. Sahakara translates it and generates an audio note in each person's preferred language.

Daily load meter

A gentle warning when a day's tasks add up to more than one person can realistically do.

Attendance & leave

Quick check-in and check-out, leave requests and approvals, with Sri Lankan public and Poya holidays built in.

Transparent payroll

Monthly, daily, hourly or per-visit pay. Advances and deductions are tracked and visible to both sides.

Clear contracts

Agree on duties, pay and contract duration up front, and keep it on record for everyone.

Truly multilingual

Breaking the language barrier at home

The owner writes a task in English; the domestic worker reads it — and hears it — in Sinhala or Tamil. Every task is translated automatically and turned into an audio note in each person's preferred language, so nothing gets lost between them.
